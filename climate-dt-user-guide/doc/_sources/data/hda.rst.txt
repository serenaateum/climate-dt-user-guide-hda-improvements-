Harmonised Data Access (HDA)
=============================

Overview
--------

The HDA provides access to the full DestinE Data Portfolio via a single
API, including Climate DT output. It is particularly suited to users who
want to explore the broader DestinE data offering alongside Climate DT,
or who prefer a REST-based access method.

More detailed information on the HDA service is available in the https://destine-data-lake-docs.data.destination-earth.eu/en/latest/dedl-discovery-and-data-access/Harmonized-Data-Access/Harmonized-Data-Access.html


Climate DT and HDA Collections
------------------------------

Climate DT data are exposed through a set of HDA collections.

Each collection corresponds to a specific Climate DT simulation dataset and
contains the metadata required to describe the available variables,
temporal coverage, spatial coverage, models, experiments, and resolutions.

The HDA collections provide a consistent abstraction layer that allows users
to discover Climate DT resources without needing to know the underlying
storage implementation.

HDA as a STAC API
----------------

HDA implements a STAC-compliant discovery interface.

The STAC (SpatioTemporal Asset Catalog) specification provides a standard way
to describe geospatial assets and collections.

Through the STAC API users can:

* discover available Climate DT collections;
* inspect collection metadata;
* search datasets using temporal criteria;
* access dataset assets and download endpoints;
* integrate Climate DT data into third-party geospatial tools.

Climate DT Discovery Workflow
-----------------------------

The typical workflow consists of:

#. Discover the available Climate DT collections.
#. Identify the simulation of interest.
#. Explore collection metadata.
#. Select variables and temporal range.
#. Submit an HDA request.
#. Download or analyse the returned assets.

Understanding Climate DT Metadata
---------------------------------

HDA exposes metadata describing:

* model (ICON, IFS-FESOM, IFS-NEMO);
* experiment;
* generation;
* resolution;
* parameter identifiers;
* temporal frequency;
* level types.

These metadata fields can be used to identify the most appropriate dataset
for a given climate analysis.

Interactive Exploration
-----------------------

Users can interactively explore Climate DT parameters and scenarios through
the DestinE DataLake example notebooks.

The Climate DT Parameter Plotter demonstrates how to:

* discover Climate DT parameters;
* inspect parameter metadata;
* browse available scenarios;
* retrieve data using HDA;
* visualise the selected parameter.

The notebook provides a practical introduction to parameter discovery and
data access workflows.
